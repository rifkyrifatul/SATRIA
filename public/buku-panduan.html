Tim Penyusun E-Surat

BAB A: PENDAHULUAN

Sistem Informasi Persuratan (E-Surat) adalah aplikasi berbasis web yang dikembangkan secara khusus untuk memfasilitasi dan mengotomatisasi proses pengelolaan administrasi persuratan. Di era digital saat ini, manajemen persuratan yang masih menggunakan metode konvensional (manual) kerap dihadapkan pada berbagai kendala, seperti risiko kehilangan atau kerusakan arsip fisik, lambatnya proses pencarian dokumen, serta keterlambatan distribusi surat dan disposisi dari pimpinan.

Oleh karena itu, kehadiran E-Surat menjadi sangat krusial. Sistem ini dirancang dengan keunggulan sebagai berikut:

  • Efisiensi Birokrasi: Mengurangi waktu yang dihabiskan untuk mencatat dan mendistribusikan surat secara fisik, sehingga mempercepat alur informasi antar divisi/bidang.
  • Pencatatan Arsip Digital yang Rapi: Seluruh surat masuk, surat keluar, beserta dokumen lampirannya akan didigitalkan dan tersimpan secara terpusat, memudahkan pencarian (retrieval) data dalam hitungan detik.
  • Kemudahan Disposisi Tanpa Batas Ruang dan Waktu: Pimpinan dapat memantau kotak masuk, memberikan instruksi, dan melakukan disposisi surat secara real-time dari perangkat apa saja (laptop, tablet, atau smartphone), tanpa harus berada di kantor.

BAB B: SPESIFIKASI SISTEM

Untuk dapat menjalankan Sistem Informasi Persuratan (E-Surat) dengan lancar dan optimal, terdapat kebutuhan spesifikasi minimal, baik di sisi Server maupun Client (Pengguna).

💻 1. Minimum Server

  • Prosesor: Intel Xeon / AMD EPYC (Min. 2 Core)
  • RAM: Min. 4 GB (Rekomendasi 8 GB+)
  • Penyimpanan: SSD 50 GB
  • OS: Linux (Ubuntu 22.04 / Debian) atau Windows
  • Software: Nginx/Apache, PHP 8.1+, Laravel 10/11, MySQL 8.0

📱 2. Minimum Client/User

  • Perangkat: PC, Laptop, Tablet, Smartphone
  • RAM: Minimal 2 GB
  • Layar: Minimal 1024x768 piksel
  • Browser: Chrome, Firefox, Edge, Safari versi terbaru

BAB C: PROSEDUR PENGGUNAAN

Sistem E-Surat dibangun dengan antarmuka yang ramah pengguna (user-friendly). Berikut adalah panduan langkah demi langkah berdasarkan alur penggunaan dan hak akses.

1. Halaman Landing / Index Aplikasi

Halaman ini adalah pintu gerbang utama (beranda publik) sebelum pengguna terotentikasi memasuki sistem. Memuat informasi umum aplikasi dan akses form login.

[Gambar 1: Tampilan Halaman Landing / Index Aplikasi]
Langkah-langkah Akses:
  1. Buka peramban web (browser) di perangkat Anda.
  2. Ketikkan alamat URL aplikasi E-Surat pada kolom address bar.
  3. Tekan Enter. Anda akan diarahkan ke Halaman Landing Aplikasi.
  4. Klik tombol Login atau Masuk Sistem untuk melanjutkan ke proses otentikasi.

2. Proses Login System

Halaman Login difungsikan sebagai lapis keamanan untuk memverifikasi hak akses (role) pengguna.

[Gambar 2: Tampilan Halaman Login System]
Langkah-langkah Login:
  1. Masukkan Username (atau Email/NIP) Anda pada kolom isian pertama.
  2. Masukkan Password (kata sandi) Anda dengan benar. Pastikan tombol Caps Lock tidak aktif jika sandi menggunakan huruf kecil.
  3. Klik tombol Login.
  4. Jika valid, sistem akan otomatis mengarahkan Anda ke Dashboard sesuai hak akses Anda. Jika gagal, peringatan merah akan muncul.

3. Hak Akses ADMIN

Administrator memiliki kendali penuh pada konfigurasi sistem, mengelola akun, dan menyiapkan master data.

3.1 Dashboard Admin

[Gambar 3: Tampilan Dashboard Admin]

Penjelasan: Menyajikan ringkasan statistik (jumlah user aktif, instansi, total surat masuk/keluar) dalam bentuk grafik dan card informasi.

3.2 Manajemen Data Pengguna

[Gambar 4: Tampilan Manajemen Data Pengguna]
Cara Menambah Pengguna:
  1. Klik menu Pengguna atau Manajemen User.
  2. Klik tombol + Tambah User Baru.
  3. Isi form data: Nama Lengkap, Username/NIP, Password, dan Hak Akses (Role).
  4. Klik tombol Simpan.

5.2 Kotak Masuk Surat

Cara Membaca Surat:
  1. Klik menu Kotak Masuk. Surat baru ditandai tebal (bold).
  2. Klik tombol Lihat Detail (ikon mata) di baris surat.
  3. Dokumen PDF akan langsung terbuka di jendela sistem tanpa perlu diunduh.

5.3 Proses Disposisi Digital

[Gambar 12: Tampilan Proses Disposisi Digital]
Cara Disposisi:
  1. Setelah membaca surat, geser layar ke bagian Form Disposisi.
  2. Pilih Tujuan: Centang nama Staf / Divisi yang dituju.
  3. Pilih Sifat: (Biasa, Segera, Rahasia).
  4. Isi Instruksi: Ketikkan arahan spesifik untuk bawahan.
  5. Klik Simpan & Kirim Disposisi.
